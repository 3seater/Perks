# Perks social graphics — approved style

Reference: perks-docs-live.svg (approved by user).

- Default post canvas: 1600 × 900, 16:9. Deliver editable standalone SVG, inline-SVG HTML, and PNG preview.
- Match the website: deep navy #060b14 / #09182b, restrained blue ambient light, blue glass surfaces, thin icy borders. Avoid bright blue full backgrounds for informative posts.
- Use the actual public/perks-mark.svg. Main wordmark matches desktop header: Arial/Helvetica, 39px, weight 600, letter-spacing -2.5px, 6px gap, 37px icon. Scale the complete lockup together (approved graphic uses 1.3×).
- Main text: Arial/Helvetica, regular weight, tight kerning, near-white #f4f8ff; accent important words with #89c6ff. No unnecessary uppercase eyebrow above the title.
- Social pills: perksp.ad and @perkspad, content-fitted with consistent padding. Approved placement is top right; main logo top left.
- Build a composition appropriate to the subject. Do not duplicate a reference composition blindly. Keep decorative lines, sparkles, and unrelated floating objects out.
- Browser mockups: one thin rounded frame, minimal top bar with small Perks mark, URL and arrow. No layered backplates or traffic-light buttons. Any glow must follow the exact outline, centered with no offset.
- Preserve editable vector layers and text. Do not add unsupported amounts, percentages, transaction identifiers, or claims to announcement artwork.

- Approved shared background: use approved-background.json via apply-graphic-background.cjs. Oversized low-contrast embossed logo contours, soft blue light across the frame, and a shaded center for readable text. This is the default background for future post graphics.
